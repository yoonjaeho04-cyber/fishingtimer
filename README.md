# 안개호수 낚시꾼 (Fishing Timer)

작업하는 시간만큼 낚시가 되는 집중 타이머 게임이에요. 설치 없이 브라우저에서 돌아가요.

## 시작하기 (Windows)

1. Chrome 또는 Edge로 이 주소를 열어요: **https://yoonjaeho04-cyber.github.io/fishingtimer/**
2. 견습 어부를 고르고 **출항**을 눌러요. 작업하는 동안 알아서 낚시해요.
3. 작업이 끝나면 **귀항**. 잡은 물고기를 팔거나 어항에 넣어요.
4. 작은 창으로 띄워 두려면 **위젯 모드**를 눌러요. 다른 창 위에 계속 떠 있어요.

## 알아두기

- 기록은 그 브라우저 안에 저장돼요. 같은 브라우저로 같은 주소를 열면 이어져요.
- 소리는 첫 클릭 후에 나와요. 끄려면 스피커 버튼.
- 설정에서 목표 시간과 휴식 타이머를 정할 수 있어요.
- 업데이트는 자동이에요. 새로고침하면 최신 버전이에요.
